# F01 — Legacy application certification

Status: **IN PROGRESS**

This evidence file records only behavior verified from the repository or from reproducible checks. It must not be used to claim that the legacy application is production-ready.

## Initial source audit

The Express application imports both `formRoutes` and `integrationRoutes`, but the application currently does not mount either router. They are therefore disconnected from the running API despite having route/controller implementations.

These routers are intentionally **not mounted by this F01 increment** until their trust boundaries are reviewed:

- `formRoutes` contains a public form-submission endpoint and accepts action-related data from the request body.
- `integrationRoutes` exposes payment creation/capture, dynamic outbound fetch, CRM submission and arbitrary webhook-dispatch handlers.
- The integration controller currently accepts payment values, remote URLs, webhook destinations and a webhook secret directly from request input and does not apply route-level authentication in the router.

Making those endpoints reachable before F02/F04 authorization, trusted published-form configuration and outbound-request policy are established would turn a disconnected feature into a security risk.

## Implemented in this increment

- Expanded `scripts/inventory.mjs` from a route-line grep into a repeatable F01 static inventory.

- Review manual SQL under `backend/prisma/manual/` against a disposable database.

- End-to-end baseline tests for the critical workflows.
